# Project: Exzur A. Lat — Personal Developer Portfolio & Techtal Studios

Act as full-stack developer, UI/UX designer, and creative director. Build a complete, modern, responsive personal developer portfolio website for **Exzur A. Lat**, featuring **Techtal Studios** as his independent creative technology studio brand.

The website should feel like a professional developer portfolio combined with a minimalist indie development studio.

## 1. Brand Identity

**Personal Identity**
- Name: Exzur A. Lat
- Professional Title: Aspiring Software Developer
- Other Interests: Game Development, 3D Modeling, Software Engineering
- Education: Bachelor of Science in Computer Science, STI College Lucena
- Location: Philippines

**Studio Identity**
- Brand: TECHTAL STUDIOS
- Description: Independent Creative Technology Studio
- Tagline: "Creating Digital Experiences Through Code and Creativity."
- Founder: Exzur A. Lat

Important: Techtal Studios is currently a personal creative brand, not yet a registered company. Do not describe it as an incorporated or officially registered business.

## 2. Visual Design

Create a premium, minimalist, dark-themed interface.

Design direction:
- Primary background: Near-black (#080808).
- Secondary background: Dark charcoal (#111111).
- Primary text: White.
- Secondary text: Muted gray.
- Accent: Subtle electric blue or cool silver.
- Typography: Modern sans-serif, preferably Inter, Geist, or similar.
- Use subtle animations, transitions, and hover effects.
- Use thin borders and restrained gradients.
- Incorporate very subtle binary patterns or technical grid details.

Avoid:
- Excessive glowing effects.
- Overly complicated backgrounds.
- Generic AI-generated website aesthetics.
- Excessive rounded cards.
- Unnecessary animations.
- Bright, distracting colors.

The website should be clean, sophisticated, and professional.

## 5. Deployment

Prepare the project for deployment on Vercel.

Requirements:
- Include a working package.json.
- Configure Next.js properly.
- Include a README.md with installation and deployment instructions.
- Ensure the project can run locally.
- Ensure the production build succeeds.
- Use environment variables for any external services.

## 6. Development Instructions

Before implementation:
1. Plan the website architecture.
2. Establish the design system.
3. Create the component structure.
4. Implement the website section by section.

After implementation:
1. Run the development server.
2. Test all navigation links.
3. Test responsiveness.
4. Check for console errors.
5. Run the production build.
6. Fix any issues found.

Do not stop after generating a visual mockup. Build the actual working website.

## Final Design Goal

The finished website should communicate two things:

1. Exzur A. Lat is an aspiring software developer with interests and practical experience across different areas of technology.
2. Techtal Studios is the independent creative brand through which he intends to develop, publish, and eventually sell his own games, 3D assets, and software.

Make the result feel like a portfolio belonging to a serious aspiring developer who is building something of his own.
